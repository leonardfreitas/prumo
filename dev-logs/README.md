# Development log

History, kept for context. **Nothing here is referenced by `docs/`, by the README or by the website, and
nothing here is maintained.**

These two files recorded the architecture and stack phase while it was being decided, one question at a
time. That phase is over: what is in force now is `docs/stack.md`, `docs/structure.md` and the knowledge
base in `.prumo-templates/`, which are written to be read rather than to be reconstructed from a log.

| File | Held |
|---|---|
| [`DECISIONS.md`](DECISIONS.md) | 285 entries: the options weighed, why one won, what it cost |
| [`OPEN-QUESTIONS.md`](OPEN-QUESTIONS.md) | What had been raised and was still unresolved when the log was closed |

Read them to understand *why* something is the way it is. Do not treat them as current: where one of them
disagrees with `docs/`, `docs/` is right.
